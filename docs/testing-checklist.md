# Testing Checklist – Photobox App

## 1. Kamera
- Kamera muncul di dropdown.
- Bisa memilih kamera.
- Preview kamera muncul.
- Resolusi berubah ketika di-set.

## 2. Capture
- Timer countdown bekerja.
- Foto tersimpan di galeri.
- Bisa mengambil 4 foto.

## 3. Layout A4 Landscape
- Hasil landscape (tidak portrait).
- Grid 2×2 rapi.
- Watermark muncul.
- Preview tampil.

## 4. Download
- Download A4 berjalan.
- Download foto tunggal berjalan.

## 5. Error Handling
- Tidak crash ketika kamera tidak ditemukan.
- Upload gambar manual bekerja.

## 6. Performa
- Tidak lag saat generate gambar.
- Hasil cetak tidak blur.
