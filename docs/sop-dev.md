# SOP Kerja Developer  
Self Photoshoot / Photobox App

## 1. Tujuan
Developer mengubah desain dari tim DKV menjadi aplikasi web yang dapat digunakan.

## 2. Alur Kerja Developer
1. Baca desain dari Figma.
2. Buat tampilan Blade sesuai desain.
3. Pastikan UI mirip desain minimal 90%.
4. Implementasikan fitur step-by-step:
   - Kamera → Countdown → Capture → Gallery → Export A4.
5. Gunakan AI Agent jika perlu, tapi arahkan dengan jelas.
6. Jika bingung, tanya PM.

## 3. Aturan Kerja
- Jangan ubah desain tanpa izin.
- Satu pekerjaan = satu branch.
- Semua perubahan harus lewat Pull Request.
- Setelah coding, lakukan testing dasar sebelum minta review.

## 4. Tools
- VSCode
- Browser Chrome/Firefox
- GitHub (clone, commit, push)
- Laravel Artisan (serve)

## 5. Commit Messages Guide

- feat: menambahkan fitur kamera
- fix: memperbaiki bug pada capture
- style: memperbaiki tampilan tombol
- refactor: merapikan fungsi takePhoto
- docs: memperbarui dokumentasi
